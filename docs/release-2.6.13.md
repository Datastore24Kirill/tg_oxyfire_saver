# 2.6.13

- Очередь группируется: на паузе и ожидающие → скачиваемые → ошибки/отменённые/пропущенные → готовые. Внутри групп новые записи выше. При смене статуса существующая карточка перемещается без пересоздания.
- Проверка релиза и скачивание повторяются до трёх раз при временных сетевых сбоях, включая HTTP 504. Ошибки контрольной суммы и постоянные HTTP-ошибки не повторяются.
- Причина ошибки обновления остаётся в баннере.

Проверка 2026-11-09: в запущенной старой версии API сообщил HTTP 504 Gateway Time-out; установка ещё не начиналась. Python: 12 тестов успешно, 1 пропущен. JS: сортировка и локализация успешно. Пакет Mac собран, установлен через штатный помощник с резервной копией; RESTART_OK, API и UI показывают 2.6.13, Telegram онлайн. На момент живой проверки все карточки были завершены; смешанные статусы проверены тестами. Windows не проверялся. Публичный релиз не опубликован.
