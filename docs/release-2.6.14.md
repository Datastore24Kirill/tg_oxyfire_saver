# TG Oxyfire Saver 2.6.14

- Исправлены ошибки загрузки файлов с Telegram CDN, включая GetCdnFileRequest.
- Исправлен обрыв загрузки на последнем блоке файла.
- Добавлена проверка целостности скачиваемых CDN-блоков и ограничение ожидания ответа сервера.
- На Mac интерфейс восстанавливается после сбоя процесса WebKit, который мог оставлять белое окно.

## Скачать

- **Mac:** TG-Oxyfire-Saver-macOS.zip — распакуйте и запустите Install.command.
- **Windows:** TG-Oxyfire-Saver-Windows.zip — распакуйте и запустите TGOxyfireSaver.exe.
- В установленном приложении можно воспользоваться проверкой обновлений.

Очередь, настройки и вход в Telegram сохраняются при штатном обновлении.

## Проверка

Исправление проверено на Mac: четыре проблемные загрузки завершились, включая файл 26 МБ. Автотесты CDN проверяют расшифровку, целостность, последний блок и освобождение соединения при отмене. Сборки и тесты для обеих платформ выполняются в GitHub Actions. Ручная проверка интерфейса Windows не проводилась.

Контрольные суммы архивов находятся в SHA256SUMS.txt.
