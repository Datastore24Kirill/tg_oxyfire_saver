# Восстановление окна macOS, 2026-11-09

Белое окно воспроизведено: в AX были только рамка и меню, без HTML. Служба оставалась доступна на порту 63047, /api/health и / отвечали HTTP 200. Точная причина исчезновения WebKit-содержимого в старом журнале не зафиксирована.

При повторном запуске помощника без аргументов обнаружена отдельная ошибка: использовался фиксированный порт 8765 вместо записанного текущего порта. Теперь без аргументов читается .api_port.

Добавлен обработчик явного события WebKit webViewWebContentProcessDidTerminate: журналирование и reload. Само событие сбоя искусственно не вызывалось; не считать его подтверждённой причиной исходного белого экрана.

Изменение применено к локальному gui_window.py с резервной копией в updates/gui_window-before-recovery.py. После повторного запуска окно показало интерфейс и список загрузок. Служба и её очередь не перезапускались. Версия публичного релиза остаётся 2.6.13; этот патч пока в него не входит.
